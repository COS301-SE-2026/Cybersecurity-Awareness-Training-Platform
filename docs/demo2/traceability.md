# Demo 1 Traceability Matrix

## Purpose

This document links Demo 1 requirements, use cases, API contracts, domain concepts, design artefacts, and QA/test references.

## Traceability Scope

This matrix covers:

- UC-01: View emails in simulated inbox
- UC-02: View training document
- UC-03: Complete quiz flow and view results
- UC-05: Review and Manage Organisation Registrations
- UC-09: Manage Organisation Admins and Permissions
- UC-11: Configure Organisation Security Settings
- Base feature: Login/register
- Base feature: Basic themes
- Base feature: General form validation

Campaign discovery and lightweight tracking are included only where they support these Demo 1 flows. UC-05, UC-09, and UC-11 are included as Demo 2 planning traceability and reference planned implementation issues.
