# Demo 2 Traceability Matrix

## Purpose

This document links Demo 2 requirements, use cases, API contracts, domain concepts, design artefacts, and QA/test references.

## Traceability Scope

This matrix covers:

- UC-01: View emails in simulated inbox
- UC-02: View training document
- UC-03: Complete quiz flow and view results
- UC-05: Review and Manage Organisation Registrations
- Base feature: Login/register
- Base feature: Basic themes
- Base feature: General form validation

Campaign discovery and lightweight tracking are included only where they support these Demo 1 flows.
