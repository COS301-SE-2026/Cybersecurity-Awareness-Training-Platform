## 2. Classification Notes

- Deterministic checks are suitable for normal local verification and can become CI gates if the team decides to wire them in.
- Accessibility checks are executable now, but should not be made a required CI gate while the registration page still has a known critical violation.
- Performance and deployment checks are release/manual checks unless the required services, data, and host configuration are made stable in CI.
- Failed evidence should remain visible. The target should be fixed or explicitly deferred; the evidence should not be edited to look passing.
